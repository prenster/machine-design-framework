# Toolchain

Principle: **the repo is the source of truth, in text.** GUI tools are for viewing, commissioning
and manufacturing. They get files exported from the repo, and their exports come back into git.

## Core (free, scriptable: what Claude works in)

| Need | Tool | Notes |
|---|---|---|
| Data, schemas, checks | Python 3, PyYAML, jsonschema, numpy, scipy, shapely | This repo, `make verify` |
| 3D collision | trimesh + python-fcl, manifold3d for exact overlap | SWEEP-3D |
| PLC SIL | lark (ST parser) → Python transpiler | PLC-COMPILE, SIL-* |
| Parametric 3D CAD | **build123d** (or CadQuery), OpenCascade kernel | Code → STEP/STL/GLB. Catalog STEP models imported as-is |
| 2D drawings | build123d projection/SVG export, FreeCAD TechDraw | Drawings always get human review (G4) |
| Multibody / flexible sim | **Project Chrono** (PyChrono) | Rigid + FEA shells/cables; heavier |
| Fast rigid-body sim | MuJoCo | Fast kinematics/contact; no paper physics |
| Soft-PLC for SIL | **CODESYS** Development System + Control Win/Linux (soft-PLC) | IEC 61131-3 ST, SoftMotion cam tables |
| Electrical | QElectroTech or KiCad | I/O list as data → schematics |

## Viewing without installing much

Claude can turn anything in the repo into something viewable in a browser:

- **Side views, timing charts, reports**: SVG/Markdown generated by `make verify` (`build/`).
- **3D models**: build123d → GLB → a self-contained HTML page with an orbit viewer (three.js),
  published as a private link. No CAD install needed to look, rotate and section.
- **Drawings**: SVG/PDF from the CAD code.

For local, offline 3D viewing of STEP files, any free STEP viewer works: FreeCAD, Open Cascade CAD
Assistant, or eDrawings Viewer (Windows). You only need one.

## SEW-Eurodrive MOVI-C / MOVISUITE

- MOVISUITE is free, Windows-only and GUI-driven. Claude does not operate it day to day.
  Claude **generates** what it consumes:
  - cam tables (from `cycle.yaml`)
  - axis/module parameter sets
  - IEC 61131-3 code for sequencing and interlocks.
  
  You import and commission. MOVISUITE exports go back into git.
- Confirm with SEW which file import/export formats your MOVISUITE version supports for cam tables
  and parameter sets. That determines how automated the handoff is.
- The MOVI-C controller is programmed in the **CODESYS-based MOVIRUN open Editor** (SEW's IEC editor,
  opened from MOVISUITE), which also tests the program in simulation or on real hardware. CODESYS is not
  an alternative to MOVI-C; it is the engine inside it. So installing MOVISUITE gets you the real compiler
  and simulator for the exact controller. The framework's ST transpiler is the fast pre-check that runs
  on every commit; the MOVIRUN editor is the authoritative check before commissioning.
- MOVIKIT motion modules (camming, gearing...) are used from IEC code through PLCopen-style interfaces.
- Data from existing machines: MOVISUITE scope/diagnostic exports (CSV) are good calibration data.
  Commit them under `tests/data/` and reference them from `tests.yaml`.
- Possible, but not the default: Claude driving the MOVISUITE GUI through computer use on a Windows
  PC. It's slower and more fragile than file exchange; use it only for one-off reads.

## Bench controller ("basic controller")

To test real control code and real motion before the machine exists:

1. **Cheapest:** CODESYS Control on a PC or a Raspberry Pi (low-cost runtime license) + stepper/servo
   drives on the kinematic mock-up. Tests logic, timing and cam tables.
2. **Closest to production:** one SEW MOVI-C controller + one catalog servo axis running the generated
   cam table. Measures real following error and valve/sensor timing. The parts get reused later.

## Paid tools worth considering

| Tool | What it buys you | When it's worth it |
|---|---|---|
| **Onshape** (paid tier) | Real parametric CAD with full REST API and FeatureScript, so agents can drive real CAD; proper drawings; browser-only | When code-CAD drawings become the bottleneck (phase 3–4) |
| **Beckhoff TwinCAT 3** | Mature virtual commissioning and motion; engineering environment free to download | If you want SIL beyond CODESYS |
| **ISG-virtuos / Siemens NX MCD** | Industrial virtual commissioning (digital twin with PLC in the loop) | Full machine, commercial project scale |
| **EPLAN Electric P8** | Industry-standard electrical CAD, panel layout, wire lists | When the panel gets big or a panel shop needs EPLAN files |
| **MATLAB + Simscape Multibody** | Polished multibody dynamics + control design | If Chrono's learning curve costs more than the license |
| **Claude plan with Fable 5.2 headroom** | TIER-A work without running out | From phase 0 on |

## Viewing designs without CAD software

- **Cycle video:** `python mdf.py animate [PROJECT] --variant nominal` writes
  `<project>/build/cycle-<variant>.mp4`: 3D station with bodies moving per `cycle.yaml`, product
  state (gripped / placed / glue), the segment notes as captions, and a timing strip with a cursor.
  Needs ffmpeg (`winget install ffmpeg` on Windows, `apt install ffmpeg` on Linux).
  The video is generated from the same model the checks use, so it shows what was verified,
  not an artist's impression. It is a review aid, not a check.
- **Static renders:** `make verify` writes PNG renders into `build/`.
- **STEP files:** exported to `build/` for anyone who wants to orbit the model. Any free viewer
  works (FreeCAD, eDrawings Viewer, CAD Assistant). Not required.
